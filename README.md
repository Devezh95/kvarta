# Кварта — лендинг обжарки кофе

**Демо:** https://kvartacoffee.netlify.app/

Лендинг для небольшой обжарки кофе «Кварта» из Минска. Основной акцент — свежесть зерна, понятный ассортимент и удобная подача заявки с телефона.

## Стек

- Next.js, React, TypeScript
- Tailwind CSS
- Neon PostgreSQL для хранения заявок
- Netlify для деплоя

## Что реализовано

- Адаптивный лендинг с информацией об обжарке, ассортиментом, ценами, подпиской и доставкой.
- Форма заявки: имя, белорусский номер телефона, тип обращения и комментарий.
- Серверная валидация данных и понятные сообщения об ошибках.
- Защита от повторной отправки заявки с одного номера в течение 10 минут.
- Сохранение заявок в PostgreSQL.
- Передача источника, рекламного объявления, страницы входа и UTM-меток вместе с заявкой.

Корзину и онлайн-оплату не реализовывал, поскольку по ТЗ менеджер связывается с клиентом и оформляет заказ вручную.

## Работа с ИИ

Использовал ИИ как помощника при разработке: для проработки структуры компонентов, реализации отдельных частей интерфейса, формы и серверной логики. Архитектурные решения, интеграцию частей проекта, проверку результата и исправление ошибок выполнял в процессе собственной работы.

В процессе обнаружилась проблема с хранением заявок в JSON-файле: локально такой подход работал, но в Netlify серверная функция не могла создать директорию для записи. Вместо попытки сохранить данные в файловой системе перенёс хранение заявок в Neon PostgreSQL.

Также при сборке Next.js возникла несовместимость настройки `runtime` с включённым `cacheComponents`. По сообщению сборки убрал эту настройку и повторно проверил production-сборку.


## Запуск локально

1. Установить зависимости: `npm install`.
2. Создать `.env.local` в корне проекта и добавить строку подключения к Neon:

   `DATABASE_URL="я сброшу отдельно"`
3. Запустить проект: `npm run dev`.
4. Открыть http://localhost:3000.
